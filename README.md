# meeting-manager-frontend

Next.js UI for Meeting Manager. Can run standalone or as the `frontend/` submodule of
[meeting-manager](https://github.com/Mrdiamond096/meeting-manager).

```bash
make up      # Next.js dev server in docker → http://localhost:3001 (expects API on :3000)
make test    # run tests
make help    # all targets
```
